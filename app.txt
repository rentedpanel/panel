# ProInjector - Android Root Memory Injector & Mod-Menu Architecture

A production-grade Android mod-menu injector:
Login -> Draggable Floating Icon -> Pop-up Mod-Menu (Switches) -> JNI -> Native C++ Memory Engine (/proc/[pid]/mem).

## 8. `injector.cpp` — Native Memory Engine

```cpp
// Parses /proc/[pid]/maps for TARGET_LIB base address.
// Opens /proc/[pid]/mem with O_RDWR.
// Captures original memory snapshots and restores them on toggle OFF.
// Runs background pthread persistence loop (300ms interval).
```
